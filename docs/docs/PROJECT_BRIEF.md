# Краткое описание проекта

## Название

`news-summarizer`

## Что это за продукт

`news-summarizer` — Telegram-сервис персональных новостных сводок. Он собирает новости из RSS-источников, удаляет повторы, анализирует материалы через Yandex AI Studio и отправляет пользователю краткую выжимку по интересующим темам.

## Какую проблему решает

Новостной поток перегружен повторами, длинными текстами и нерелевантными материалами. Пользователю нужно быстро понять:

- что произошло;
- почему это важно;
- насколько это срочно;
- есть ли в новости полезная возможность или гипотеза;
- стоит ли читать полный источник.

## Целевой пользователь

- пользователи, которые хотят быстро следить за выбранными темами;
- специалисты и предприниматели, которым важны тренды, рынки и технологии;
- студенты и исследователи, которым нужна короткая выжимка из потока новостей;
- команды, которым нужен общий AI-фильтр новостей.

## Основной функционал

- регистрация пользователя через Telegram;
- настройка интересов и срочных тем;
- сбор новостей из источников;
- дедупликация новостей;
- AI-анализ каждой новости;
- ежедневная сводка;
- сводка возможностей;
- срочные уведомления;
- подробный AI-анализ отдельной новости.

## Использование Алиса AI / Yandex AI Studio

Yandex AI Studio встроен в бизнес-логику:

1. Модель возвращает JSON с категорией, важностью, срочностью и summary.
2. AI оценивает важность, срочность и потенциал новости.
3. AI объясняет, почему материал важен для пользователя.
4. По запросу пользователя AI готовит подробный разбор новости.
5. Embeddings используются для поиска смысловых дублей.

## Роль AI в сервисе

Пользователь не просто пишет вопрос модели. AI работает внутри сервиса:

```text
новость -> AI-анализ -> структурированные признаки -> бизнес-правила -> персональная сводка
```

Результат модели определяет, попадёт ли новость в дайджест, сводку возможностей или срочное уведомление.

## Что уже реализовано

- .NET backend;
- PostgreSQL-хранилище;
- Telegram-бот;
- Worker pipeline;
- mock и RSS-источники;
- Yandex AI provider;
- Yandex Embeddings provider;
- базовая и семантическая дедупликация;
- debug endpoints для демонстрации;
- тесты для основных модулей.

## Ограничения MVP

- нет web UI;
- нет production-ready очередей;
- нет сложной модели персонализации;
- качество зависит от RSS-источников;
- semantic deduplication требует включённых embeddings;
- debug endpoints предназначены только для локальной демонстрации.

## Перспективы развития

- подключение Алисы как голосового интерфейса;
- web dashboard для настройки источников и интересов;
- RAG по архиву новостей и документам пользователя;
- агентные сценарии с function calling;
- корпоративные дайджесты для команд;
- интеграция с CRM, почтой, календарём или внутренними базами знаний;
- платная подписка на персональные и командные AI-сводки.

## Коммерческий потенциал

Продукт можно развивать как:

- персональный AI news assistant;
- корпоративный мониторинг новостей и рисков;
- инструмент для аналитиков, стартапов и исследовательских команд;
- white-label Telegram/Алиса-бот для отраслевых новостных дайджестов.
