# news-summarizer

`news-summarizer` — Telegram-сервис, который собирает новости из выбранных источников, убирает очевидные повторы, оценивает релевантность с помощью AI и отправляет пользователю краткие сводки по интересующим темам.

## Цель проекта

Сделать MVP, который показывает полный рабочий цикл:

```text
сбор новостей → фильтрация → AI-оценка → сводка → отправка в Telegram
````

Проект не привязан к одной тематике. Пользователь может следить за политикой, экономикой, спортом, технологиями, наукой, культурой, локальными событиями или собственными темами.

## Основные бизнес-решения

* Сервис работает вокруг интересов пользователя, а не вокруг одной новостной категории.
* Пользователь подписывается на темы и источники.
* Источники могут быть RSS-лентами, новостными сайтами или другими платформами.
* MVP не пытается идеально парсить весь интернет: сначала поддерживаются простые и стабильные источники.
* Повторы новостей удаляются на базовом уровне: по ссылке, заголовку, источнику и похожести текста.
* AI используется не для сбора новостей, а для оценки, фильтрации и краткого пересказа.
* В базе хранятся только актуальные новости. Старые записи должны удаляться по сроку жизни.
* Главный результат для пользователя — короткая полезная сводка, а не поток сырых ссылок.

## Основные сценарии

### 1. Сбор новостей

Сервис периодически обходит подключённые источники и сохраняет новые материалы.

### 2. Фильтрация

Система отбрасывает очевидный мусор, дубликаты и устаревшие новости.

### 3. AI-оценка

AI оценивает, насколько новость подходит под интересы пользователя.

### 4. Формирование сводки

Из подходящих новостей формируется короткий summary: что произошло, почему важно, ссылка на источник.

### 5. Отправка в Telegram

Пользователь получает готовую подборку в Telegram-боте.

## Технологии

Планируемый стек MVP:

* Backend: `.NET`
* База данных: `PostgreSQL`
* Интеграция с Telegram: `Telegram Bot API`
* Сбор новостей: `RSS`, HTTP-запросы, HTML-парсинг при необходимости
* AI-обработка: LLM API или локальная модель
* Инфраструктура: `Docker`, `Docker Compose`
* Документация и схема данных: `Markdown`, `DBML`

## Что входит в MVP

* хранение источников новостей;
* периодический сбор новостей;
* сохранение новостей в БД;
* удаление устаревших новостей;
* базовая дедупликация;
* AI-оценка релевантности;
* генерация краткой сводки;
* отправка результата в Telegram.

## Что не входит в MVP

* полноценный веб-интерфейс;
* сложная персонализация рекомендаций;
* поддержка всех сайтов и платформ;
* идеальная семантическая дедупликация;
* аналитика поведения пользователя;
* масштабирование под большую нагрузку.
